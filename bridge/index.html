How it works

No new token. Supply unchanged.

The Robinhood contract is the official omnichain deployment of $HIVE, paired with the original token on Base through LayerZero's audited OFT standard. Bridging Base → Robinhood locks tokens in the adapter and mints on Robinhood; bridging back burns and unlocks. Beware of copycats — the only official addresses are in the table below.

Hardened beyond the standard

This bridge adds protections most OFT bridges skip: dual-window (hourly + daily) rate limits in both directions so no single incident can drain the lockbox quickly, an emergency pause, timelocked governance so every risk-increasing change is publicly delayed, and a bridge fee that is hard-capped at 0.25% in the contract itself — currently —. Security is verified by two independent DVNs (LayerZero Labs + Nethermind), with directional finality and every transfer traceable on LayerZero Scan.

Getting started

  1. Add the network with the button above (MetaMask, Rabby, Coinbase Wallet, any EVM wallet).
  2. Get ETH for gas on Robinhood. On testnet, use Robinhood's official faucet. On mainnet, use a supported canonical bridge or exchange withdrawal. Without gas you cannot bridge back.
  3. Bridge your HIVE with the widget above.
  4. Buy or sell with Base liquidity. The routed widget uses the canonical Base HIVE market when its provider supports both chains; no Robinhood HIVE pool is required.
