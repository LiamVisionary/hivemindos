# Scroll World web template

This starter is adapted from [`oso95/scroll-world`](https://github.com/oso95/scroll-world) at commit `2912048246d057cdfe134dfc0b4dfb7e6a12f30e` under the MIT license.

The template includes the portable browser engine, an adapted page/config, and local SVG posters so the project previews without external services. Replace the posters with your own stills and add `clip`, `clipMobile`, and connector paths in `script.js` when frame-matched video is available.

The upstream repository also documents optional shell, Python, ffmpeg, Codex, and Higgsfield generation workflows. HivemindOS does not install or run those workflows when this template is attached. Any paid generation remains a separate, explicit user-approved action.
