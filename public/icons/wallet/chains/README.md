# Wallet Chain Badges

Tiny compressed SVG chain badges used in compact wallet token rows.

- `base.svg`
- `solana.svg`
- `robinhood.svg`

Source: `base.svg`/`solana.svg` adapted from the MIT-licensed `0xa3k5/web3icons` network background SVGs; `robinhood.svg` is a hand-drawn stylized quill in Robinhood green.
