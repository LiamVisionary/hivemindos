# Vignelli Canon Design System

Apply a disciplined modernist design-system approach to identity, wayfinding, publication, or interface work.

## Use

Use this when the request needs order, restraint, clarity, consistency, and long-term brand equity. Do not use it when the user wants expressive illustration, maximalism, chaotic collage, or trend-first brand exploration.

## Principles

- Semantics first: understand the meaning before designing the form.
- Discipline over novelty: reduce arbitrary choices.
- Grid as structure, not decoration.
- Few typefaces, few sizes, strong spacing.
- Color as identifier or hierarchy, not wallpaper.
- Consistency creates trust.

## Workflow

1. Define the semantic core: what the artifact is, who uses it, and what must be unmistakable.
2. Choose the system parts: grid, type scale, palette, icon/mark rule, spacing, materials, and usage constraints.
3. Produce sample applications across at least three contexts so the system proves itself.
4. Write usage rules and failure cases.
5. Verify accessibility, text wrapping, and real content density.
