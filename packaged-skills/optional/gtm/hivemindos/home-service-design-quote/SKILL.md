# Home Service Design Quote

Create an estimated design-and-quote package for a home-service job.

## Contract

This skill creates estimates, not professional measurements, permits, engineering advice, legal quotes, or binding bids. Mark uncertain quantities and require a contractor review before customer delivery.

## Inputs

- Customer-approved photo(s), address or climate/region when relevant, desired style, budget range, and must-keep/must-remove items.
- Service category: landscaping, patio, garden, lighting, exterior refresh, interior room, painting, or similar.
- Output target: concept brief, generated visuals, itemized estimate, interactive quote page, or Work Board sales package.

## Workflow

1. Inspect the supplied image and list visible constraints.
2. Ask for missing essentials only: service type, rough size, budget, style, and delivery region.
3. Create three concepts: economical, balanced, and premium.
4. Estimate quantities with clear assumptions. Use ranges when measurements are uncertain.
5. Draft an itemized quote with labor/material categories, optional add-ons, timeline, and exclusions.
6. If generating before/after visuals, preserve the original camera angle and avoid impossible structural changes.
7. Package the result with confidence, assumptions, and contractor-review checklist.

## Capability Map

- Image editing/generation: select a discovered tool that can preserve the source photo. Verify nonblank before/after outputs.
- Measurements: use user-supplied dimensions first; otherwise state estimates as rough.
- Page artifact: build a responsive calculator or quote page only when requested.
- External delivery: require approval before sending to a customer.

## Safety

- Do not imply permit approval, code compliance, structural safety, or final pricing.
- Do not expose home addresses in public artifacts.
- Do not upload private property photos externally without approval.
