# Venue Activation Visualizer

Turn venue photos and brand constraints into reviewable activation concepts.

## Inputs

- Venue name or supplied photos.
- Brand, sponsor, campaign, or event objective.
- Required surfaces: stage, booth, signage, lounge, entry, projection, merch, photo wall, or wayfinding.
- Output format: image prompts, generated before/after images, interactive page, or deck.

## Workflow

1. Gather venue evidence. Prefer user-supplied photos or rights-cleared venue media. If searching the web, cite what was used.
2. Identify fixed constraints: sight lines, exits, accessibility paths, lighting, scale, and surfaces that should not be covered.
3. Propose three activation levels: light-touch, standard, and hero takeover.
4. For each concept, specify what changes and what must remain untouched.
5. Generate or prompt before/after visuals while preserving the real architecture.
6. Verify that logos, text, exits, and people are not distorted in a way that misrepresents feasibility.
7. Package with a production checklist and unanswered venue-permission questions.

## Capability Map

- Image generation/editing: use a discovered image tool that supports references or editing. Verify outputs.
- Web/page artifact: use frontend design guidance for comparison toggles.
- Delivery: send only with approval and receipt if shared externally.

## Safety

- Do not claim venue approval or code compliance.
- Do not use private venue photos in external generators without approval.
- Mark dimensions and pricing as estimates unless measured and sourced.
