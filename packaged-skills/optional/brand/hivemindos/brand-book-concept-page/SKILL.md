# Brand Book Concept Page

Generate a small set of distinct brand directions and package them into a usable concept artifact.

## Contract

The output is exploratory brand work, not a trademark clearance, final legal identity, or guaranteed original mark. Use original language and generated or licensed assets. Do not imitate a living brand or copy protected logos.

## Inputs

- Product or company name, audience, category, desired feeling, and dealbreakers.
- Existing logo, screenshots, product photos, or style references if any.
- Output target: written brand book, static HTML page, dashboard-ready artifact, slide, or asset prompts.

## Workflow

1. Clarify the brand job: who needs to believe what, and what should they do next.
2. Create three meaningfully different directions. Each needs a positioning sentence, visual principle, palette, typography direction, voice rules, tagline options, and product/application examples.
3. For each direction, generate or specify assets:
   - logo concept and usage notes
   - app/product screen treatment
   - social or out-of-home application
   - merch or physical touchpoint
   - do/don't examples
4. If building a page, make the experience functional first: switchable directions, responsive layout, accessible contrast, and no hidden text truncation.
5. Verify that every direction uses different strategy, not just different colors.

## Capability Map

- Visual generation: use a discovered image generator or local media capability. Verify generated assets are nonblank and legible.
- Frontend artifact: use existing HivemindOS frontend/design guidance and run a local visual check if code is created.
- Delivery: save artifacts locally or to the requested channel only after approval.

## Safety

- Do not claim trademark availability.
- Do not use private product screenshots in external generators without approval.
- If the user wants a real launch identity, add a legal/trademark review note and source-file handoff checklist.
