# Out Of Home Subway Campaign

Create a realistic out-of-home campaign concept while avoiding misuse of transit authority marks or misleading placement claims.

## Inputs

- Brand, campaign objective, audience, city/venue type, and key message.
- Existing brand assets, usage rights, and required disclaimers.
- Output target: prompt pack, generated mockups, HTML lookbook, slide deck, or Work Board task bundle.

## Workflow

1. Define the campaign idea in one sentence and the commuter moment it exploits.
2. Create a compact visual system: headline rules, palette, logo handling, CTA, photography/illustration style, and placement hierarchy.
3. Build 4 to 8 placements:
   - platform poster
   - train interior card
   - station wall takeover
   - stair/escalator panel
   - digital billboard
   - social proof image of the campaign in context
4. Use generated or licensed location imagery. If real transit marks appear, treat them as contextual background only and avoid endorsement claims.
5. Verify legibility from distance, mobile preview, and accessibility contrast.
6. Package final assets with assumptions, rights caveats, and next steps for real media buying.

## Capability Map

- Brand strategy: use this skill plus writing-style or product-positioning skills.
- Image generation: select a discovered image generator and verify nonblank, brand-consistent results.
- Page/deck assembly: use frontend or presentation skills; test responsive sizing if HTML is created.

## Safety

- Do not present mockups as purchased placements.
- Do not imply endorsement by a transit agency, city, venue, celebrity, or competitor.
- Ask before uploading private brand assets to external tools.
