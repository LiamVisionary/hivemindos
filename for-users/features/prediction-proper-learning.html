Prediction-market Proper-learning Lab

HivemindOS can run a long-lived, research-only prediction-market experiment that learns from prospective public outcomes without placing a trade. The lab is designed to answer a narrower question than “can an AI pick winners?”: does a fully recorded evidence forecast improve proper scoring and fee-aware paper returns versus matched public-market baselines?

The lab does not promise constant profit. A high win rate can still lose money, and an apparent gain can be one concentrated outlier. Promotion therefore requires enough unique resolved markets, matched controls, outlier resistance, and independent statistical validation.

One Frozen Cohort, Six Matched Arms

Every 12-hour cohort is selected by a versioned deterministic rule from public active markets. It rejects duplicate market and event IDs, ambiguous criteria, low liquidity, one-sided books, sports and social-post counts, and resolutions outside the two-to-fourteen-day window. Selection permits no more than one market per event and two per category.

The same frozen markets and the same later public order books are used for three forecast methods:

  • the frozen market midpoint;
  • a preregistered Platt calibration of that midpoint;
  • a reviewed evidence forecast with model, runtime, prompt, instruction, skill, configuration, calibration, reviewer, source, and timestamp lineage.

Each method runs both Brier-gradient sizing and a capital-matched equal-notional control. All six arms observe the same five-minute minimum execution lag, taker fees, displayed depth limits, minimum order sizes, category and event caps, and 2% net-edge floor. A method that finds no eligible trade still receives a zero-PnL resolved observation, so it cannot improve by hiding no-signal markets.

Collection Does Not Depend On An Agent Turn

The local collector uses public endpoints only. It freezes at most one cohort per slot, appends public resolutions, records expired forecast deadlines as missed cohorts, and recomputes the scorecard and independent validation. It never writes an AI forecast. If no reviewed forecast arrives before the two-hour deadline, the cohort is retained as missingness evidence and cannot be filled later.

On macOS, install the reversible 30-minute LaunchAgent:

scripts/install-prediction-proper-learning-v2-collector.sh

Remove the schedule while preserving every experiment artifact:

scripts/install-prediction-proper-learning-v2-collector.sh uninstall

The default append-only experiment root is ~/.hivemindos/experiments/prediction-proper-learning-v2/.

Review And Evolution

The TypeScript scorecard reports closed-only position win rate, unique-market proper scores, event-cluster breadth, treatment and control PnL/ROI, drawdown, category regimes, event concentration, and leave-one-event-out PnL. Open positions are never counted as wins.

A separate Python implementation recomputes the evaluation and fails closed unless all preregistered gates pass: at least 252 unique resolved markets and four cohorts, HAC inference, a 99% circular block bootstrap, false-discovery control, a shifted-forecast placebo, probability of backtest overfit, deflated Sharpe, two positive regimes, concentration limits, and positive leave-one-event-out results.

Passing creates only a review proposal. Applying a new immutable generation requires a separate approval artifact whose digest exactly matches that proposal. Earlier V1 outcomes may initialize the first calibration model, but they are permanently excluded from V2 scoring.

Commands

pnpm prediction:proper-learning-v2 init
pnpm prediction:proper-learning-v2 step
pnpm prediction:proper-learning-v2 status
pnpm prediction:proper-learning-v2 run --cohort <id> --ai-forecasts <reviewed.json>
pnpm prediction:proper-learning-v2 score
pnpm prediction:proper-learning-v2 review
pnpm prediction:proper-learning-v2 apply --proposal <proposal.json> --approval <approval.json>

The CLI and collector contain no authentication, signing, wallet, funding, or order-submission path. Complement arbitrage remains a separate paper lab because buying both outcomes is an execution problem, while this experiment tests directional probability estimates.

Install that separate public arbitrage matrix collector with:

scripts/install-prediction-arbitrage-paper-collector.sh

It scans for 60 seconds every five minutes across binary complete-set buys and sells, negative-risk baskets/conversions, logical relations, and maker candidates. Evidence is appended under ~/.hivemindos/experiments/prediction-arbitrage-paper-monitor/. Its headline distinction is raw price gaps versus post-fee, displayed-depth paper fills; it does not borrow directional V2 forecasts.
