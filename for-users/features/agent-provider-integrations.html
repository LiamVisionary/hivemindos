Apps And Agent Providers

Connect outside tools and specialist agent services while HivemindOS keeps control of the overall job: approvals, task history, and your data stay in HivemindOS.

  • Open More → Integrations to connect an account.
  • Open More → Apps & Services to install or browse services across your machines.

Installing or connecting a provider never runs it, spends money, sends messages, or approves outside changes on its own. Catalog entries list the credential names a provider needs, never the values.

Agent2Agent (A2A)

A2A is an open protocol that lets agents built on different stacks hand each other whole tasks. MCP gives one agent tools; A2A lets two agents share work.

Outbound: HivemindOS can read another agent’s capability card, send it a task, and follow it to completion. It refuses private or local addresses unless you set that peer up on purpose, and requires encryption for anything on the public internet.

Inbound is off until you turn it on. When on, HivemindOS publishes a card describing what your fleet can take on, and accepts outside work:

  • Outside work is ordinary work. It goes on the Work Board and meets the same checks and approvals as your own tasks.
  • Accepting outside work needs your operator credential, not a scoped agent token.
  • The card never reveals your machines, agent names, models, or network. Outside callers see only a task’s state and final result.

Browser Use

Install Browser Use from Apps & Services. HivemindOS installs a pinned, verified release and never runs its upstream install script silently.

Agents use a separate browser that HivemindOS launches, with its own profile. Your own windows, tabs, and sign-ins are untouched. Screenshots are saved in HivemindOS’s own folder, and only web addresses can be opened.

Turn on Full permissions on the provider card to allow higher-risk actions: cloud browsers, using a real Chrome profile, file upload, and running JavaScript. You confirm a warning to turn it on.

Cloud browsers cost money for as long as they run. They need a Browser Use API key and Full permissions. Each has a time limit so a forgotten browser stops itself, and HivemindOS lists the ones it started so you can stop them.

MCP servers

The curated MCP catalog lists each server’s capabilities, required credential names, side effects, and safety notes. Check credentials and side effects before installing or calling one.

AgentMail MCP: use an OAuth-capable client with https://mcp.agentmail.to/mcp, or pass AGENTMAIL_API_KEY if OAuth is not available. Sending and replying are real email; confirm recipients, subject, body, and attachments first.

Robinhood Trading MCP: connect Robinhood’s official Trading MCP from Integrations → MCP Servers, sign in with Robinhood in your browser, and choose your dedicated Agentic account. HivemindOS encrypts the session and reconnects after a restart. Agents can read accounts, portfolio, orders, positions, market data, watchlists, options context, earnings, and scans. Equity orders go through Robinhood’s pre-trade review, your wallet caps, company rules when the order belongs to a company task, and an explicit CONFIRM_BUY or CONFIRM_SELL before they are placed. The Robinhood Agentic brokerage account and Robinhood Chain are separate: Robinhood Chain uses your own self-custody wallet, not a brokerage account.

X API MCP: there are two ways to connect.

  • Your own X developer app: in Integrations → MCP Servers, save X_MCP_CLIENT_ID and X_MCP_CLIENT_SECRET, sign in with X in your browser, and sync the entry to your agent runtimes. Your runtime settings never contain X secrets or tokens.
  • Managed X API: sign in through HivemindOS instead. X calls are deducted from the same HivemindOS account balance used by HivemindOS Models. The hosted pricing policy is authoritative; the current default policy uses upstream X API unit cost plus 25% markup with a $0.001 minimum debit. A default X MCP tool call is $0.005 upstream and $0.00625 retail. The downloaded app cannot change official X pricing or create credits.

X tools act with your account’s permissions. Changing bookmarks or publishing Articles needs your confirmation. A read-only X docs MCP is also available at https://docs.x.com/mcp.

RentAHuman

Add your RENTAHUMAN_API_KEY in Shared Env. Searching people, bounties, and services is read-only. Reading your conversations, rentals, transfers, escrow, and bounty applications needs the key.

Anything that messages a person, creates a bounty, books a service, opens escrow, releases a payment, or sends a transfer is prepared first. It runs only after you review the task, amount, deadline, evidence required, and destination, and confirm with RENTAHUMAN_ACTION.

Coding runtimes: OpenHands and Aider

HivemindOS checks whether OpenHands and Aider are installed and can install them for you. Once installed, agents can run background coding tasks with them, using keys already saved in Shared Env. Runs are logged in HivemindOS. For tasks that change code, use a separate working copy.

Agent mailboxes

In Agent Settings, select an agent and choose Create mailbox to give it a persistent email address. You never enter IMAP, SMTP, or password settings for each agent.

A mailbox is marked ready only when the provider can both receive and send real email for that address. If no provider is ready, HivemindOS shows what is missing instead of creating a fake mailbox.

  • AgentMail (hosted): add AGENTMAIL_API_KEY in Shared Env. Addresses use agentmail.to unless you set a verified custom domain.
  • Cloudflare Agentic Inbox (self-hosted): needs a Cloudflare domain with Email Routing and Email Sending ready. HivemindOS can create and deploy the Worker project for you, and creates each agent’s routing rule. Deploying needs your Cloudflare sign-in. Replies are drafted and sent only after approval.
  • MCP Email Server (advanced): connects an existing mailbox. Your MCP client starts it when needed. Set MCP_EMAIL_SERVER_EMAIL_ADDRESS, MCP_EMAIL_SERVER_PASSWORD, and MCP_EMAIL_SERVER_IMAP_HOST. Without MCP_EMAIL_SERVER_SMTP_HOST it is read-only.

A company’s outreach email appears in the Emails tab of its Zero Human Companies cockpit.

For developers and agents

These local HivemindOS endpoints back the features above:

Endpoint Use
GET /api/mcp/catalog The curated MCP server list.
/api/rentahuman RentAHuman actions. ?action=status lists supported actions; confirmed actions repeat the POST with confirmation: "RENTAHUMAN_ACTION".
GET / POST /api/agents/mailbox Read or create (action: "create", agentId, agentName) an agent mailbox.
GET / POST /api/cloudflare/agentic-inbox Cloudflare inbox status; action: "scaffold" creates the Worker project and action: "deploy" deploys it.
POST /api/queen-bee action: "decompose-prd" turns a PRD into an epic with linked tasks. Add preview: true to see the tasks without writing them.
