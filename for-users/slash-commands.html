Slash Commands

Type / in a HivemindOS chat to run a command. There are two kinds:

  • Dashboard commands, handled by HivemindOS itself.
  • Hermes and gateway commands, handled by the connected agent runtime.

Some runtime commands only work in that runtime’s own CLI or gateway, but may still appear in the dashboard’s help. When both kinds share a name, such as /sessions or /usage, the dashboard command runs in HivemindOS chat. Use the runtime’s own CLI for its version.

Dashboard commands

Command Aliases Purpose
/doctor /diagnostics Open fleet diagnostics and run checks.
/sessions /history Search recent runtime sessions.
/fleet   Open the fleet dashboard.
/models /providers Open agent model/provider settings.
/usage   Open Wallets and refresh runtime usage.
/alerts /notifications Open the shared alert inbox.
/brain /vault Open the shared brain.
/note <note>   Save a note to the shared brain intake folder.
/work /kanban Open the work board.
/handoff-task <machine> <task>   Send a task to the best agent on a target machine.
/swarm [number] <task>   Have a team of your chat-capable agents work on the task in parallel and return one combined result. Leave out the number to size the team automatically.
/swarm-goal <build request>   Turn a rough build request into a parallel /goal plan and send it to Queen Bee, which checks the result with browser, artifact, and independent review gates.
/swarm-sim <scenario>   Start a MiroShark simulation and show its queued status.
/image-gen <prompt> /imagine, /txt2img Generate an image and show it in chat.
/video-gen <prompt> /txt2vid, /animate Generate a video and show it in chat. An attached picture becomes the first frame.

Choosing where media is generated

When you pick /image-gen or /video-gen from the slash menu, a picker asks where to generate. If you type the prompt directly, it uses Automatic.

  • This machine: free local options. Nothing leaves the machine.
  • Other machines: free options on your other connected machines.
  • HivemindOS credits: hosted models paid from your shared credit balance. Each row shows its cost in credits.
  • Your accounts: models billed to accounts you already pay for, shared through Hivemind Content Studio.

Automatic prefers free and local, then credits, then your accounts, and tells you what it chose. Your last pick is remembered; if it isn’t available, HivemindOS falls back to Automatic and says so. Models that start from a picture need one attached to your message. Hosted picture-to-video models can’t run from chat yet.

Agents can read the same model list with the media_model_catalog tool.

AEON operator: /aeon

/aeon [request] turns the chat into an AEON operator session for your linked AEON workspace. Use it to set up an instance, edit skills or schedules, find out why a run was missed, turn the current chat into a scheduled automation, or edit STRATEGY.md, soul/SOUL.md, or soul/STYLE.md.

/aeon
/aeon move the digest to 7am Manila time
/aeon turn this chat into a weekday automation
/aeon tighten STRATEGY.md around qualified pipeline
/aeon make the writing voice less formal
  • In a company CEO chat, it uses that company’s existing AEON workspace. It never creates a second workspace or changes the company’s link.
  • It works the same when the workspace is on another linked machine.
  • Creating repositories, adding credentials, real dispatches, commits, and pushes still ask for confirmation as usual.
